# 🎓 Student Management Table & Live Clock

Tugas implementasi React Hooks (`useState` & `useEffect`) dan Looping Data (`.map()`) menggunakan Vite dan Tailwind CSS.

## 🚀 Fitur

- Menampilkan data _dummy_ mahasiswa ke dalam tabel dinamis menggunakan `.map()`.
- Menggunakan `useState` untuk menyimpan array data mahasiswa.
- Menggunakan `useEffect` dan `setInterval` untuk membuat fitur Jam Digital (_Live Clock_) yang diperbarui setiap 1 detik.
- Mengimplementasikan _cleanup function_ (`clearInterval`) untuk mencegah _memory leak_.

## 🛠️ Cara Menjalankan Secara Lokal

1. Clone repositori ini.
2. Buka terminal dan jalankan `npm install` untuk mengunduh dependensi.
3. Jalankan `npm run dev`.
4. Buka `http://localhost:5173/` di browser.
